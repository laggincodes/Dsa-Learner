COLLEGE PRESENTATION · RELEASE v1.0.0

DSA Manager

An interactive Data Structures & Algorithms visualization, practice, and personal learning tracker powered by a native C++17 engine.

Version 1.0.0

Main Objectives

  • Execute all sorting, searching, container, tree, and graph algorithms natively in C++17 without mocked browser logic.
  • Provide step-by-step interactive visualizations alongside measured runtime vs theoretical Big-O comparisons.
  • Offer a structured DSA curriculum roadmap, LeetCode problem catalogue, Markdown study notes, and spaced-repetition revision.
  • Persist all learning progress, notes, solutions, and analytics locally across restarts.

Technologies Used

Core EngineC++17 (OOP + STL)
Backend HTTPPOSIX Sockets + libcurl
Build & TestsCMake + CTest
Frontend & ExtHTML/CSS/JS + MV3

Architecture Overview

1. Presentation Layer (web/ & browser-extension/): Single-page dark developer workspace using Fetch API and SVG/DOM visualizations, paired with a minimal-permission Chromium Manifest V3 extension.

2. Transport Layer (HttpServer): Lightweight multi-route HTTP/1.1 server on 127.0.0.1 serving static assets and JSON endpoints.

3. Core Domain & Persistence (dsa_core): Object-oriented C++17 modules (Algorithms, DataStructures, BinarySearchTree, Graph, QuizEngine, LearningHub, IntelligenceHub) backed by local flat-file persistence.

Key Features & Learning Outcomes

  • Sorting, Searching, Stack, Queue, Singly Linked List, Binary Search Tree, and BFS/DFS Graph visualizers.
  • Chrono microsecond Complexity Comparator, randomized Quiz Arena, and C++17 Code Library.
  • Full Question Library, automatic per-topic progress, structured Markdown notes, Solution Library, and Spaced Repetition Revision.
  • Academic outcomes: practical mastery of C++17 memory safety, OOP polymorphism, STL containers, HTTP networking, and algorithmic complexity.
